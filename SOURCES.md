# Sources

*Reference: the research behind this plugin, for anyone checking where its methods come from.*

Job market and career ladder

- GameSoundCon, "Game Audio Jobs and Skills 2026: What Employers Are Looking For" - https://www.gamesoundcon.com/post/game-audio-jobs-and-skills-2026-what-employers-are-looking-for - analysis of 142 postings: implementation, middleware, scripting, soft skills, levels from sound designer to audio director.
- A Sound Effect, "What game audio hiring managers look for" - https://asoundeffect.com/game-audio-sound-design-hiring/ - junior/intermediate/senior expectations for reels, mixing, implementation and attitude; red flags.
- O*NET OnLine, Sound Engineering Technicians (27-4014.00) - https://www.onetonline.org/link/summary/27-4014.00 - tasks (recording, mixing, synchronising, logging recordings) and core skills.

Professional bodies and standards

- EBU R 128 (2014), Loudness normalisation and permitted maximum level - https://tech.ebu.ch/docs/r/r128-2014.pdf - -23 LUFS, ±0.5 LU, -1 dBTP, LRA, rationale for loudness over peak normalisation.
- Wikipedia, "EBU R 128" - https://en.wikipedia.org/wiki/EBU_R_128 - BS.1770 gating, momentary/short-term windows, streaming service targets.
- Game Audio Network Guild (G.A.N.G.), IESD Mix Reference Levels v03.02 - https://www.audiogang.org/wp-content/uploads/2015/04/IESD-Mix-Ref-Levels-v03.02.pdf - console -24 LUFS ±2 LU, mobile -16 LUFS, -1 dBTP, 79/76 dB SPL monitoring.
- Game Audio Network Guild, Awards - https://www.audiogang.org/awards/ - the craft areas the profession recognises (sound design, mix, music, dialogue, accessible audio, technical achievement).
- Audio Engineering Society, Technical Committee on Audio for Games - https://aes.org/community/technical-council/aes-technical-committee-audio-for-games/ - scope of interactive audio practice and standards work.

Loudness in games (ASWG and practice)

- Designing Sound, "Video games and loudness standards: interview with Sony's Garry Taylor" - https://designingsound.org/2012/07/30/video-games-and-loudness-standards-interview-with-sonys-garry-taylor/ - origin of Sony ASWG targets, 30-minute representative measurement, why games need standards.
- Designing Sound, "Loudness in game audio" - https://designingsound.org/2013/02/loudness-in-game-audio/ - measurement method, 79 dB monitoring, pitfalls.
- Audiokinetic, "Mastering a Game with Wwise, Part 1" - https://audiokinetic.com/ko/blog/mastering-a-game-with-wwise-part1 - ASWG-R001 figures (-24/-18 LUFS, -1 dBTP, LRA 20), measuring the real output, subtle mastering.
- Audio Media International, "Mobile loudness: an adaptive approach" - https://audiomediainternational.com/mobile-loudness-an-adaptive-approach/ - ASWG-R001 history, mobile targets and runtime compression.

Practitioner methods

- Audiokinetic, "Overwatch - Game Audio Using Wwise (part 1/2)" - https://www.audiokinetic.com/en/blog/overwatch-game-audio-using-wwise-1/ - "play by sound", audio as gameplay information, priority-driven dynamic mix, dense clarity.
- Audiokinetic, "Naming Convention Best Practices" - https://www.audiokinetic.com/en/blog/naming-convention-best-practices - cue and file naming rules.
- Audiokinetic, "How to Use Interactive Music to Score Gameplay" - https://www.audiokinetic.com/fr/blog/how-to-use-interactive-music-to-score-gameplay - horizontal re-sequencing, vertical layering, stingers, runtime processing.
- Game Developer, "Hybrid horizontal/vertical structure for game music composers" (GDC 2021) - https://www.gamedeveloper.com/game-platforms/hybrid-horizontal-vertical-structure-for-game-music-composers-from-spyder-to-sackboy-gdc-2021- - trade-offs of segment, layer and hybrid structures.
- Andy Farnell, *Designing Sound* (MIT Press, 2010) - https://mitpressbookstore.mit.edu/book/9780262014410 - procedural audio: analyse the physical process, model, implement.
- License guide, "Freesound" - https://licenseorg.com/guide/music-audio/freesound - per-clip Creative Commons licences and their commercial-use limits.

Documentation

- Diataxis - https://diataxis.fr - the four documentation kinds and the compass used for docs/ and workflow docs steps.
