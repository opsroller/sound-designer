# How to clear a third-party sound for use

*How-to guide: for anyone who wants to use a sound or music file they did not make.*

This guide shows you how to decide whether a library, marketplace or
community sound may ship, and how to record it.

1. Open the individual file's page, not the pack's or site's front page;
   on community sites each file can carry a different licence.
2. Read the licence text itself. Then:
   - CC0: allowed. Go to step 4.
   - CC BY: allowed if you add the required attribution. Go to step 3.
   - CC BY-SA: allowed only if the project's licence policy accepts
     share-alike for assets; ask the project-manager.
   - CC BY-NC, CC BY-ND, "personal use only", unclear or no licence:
     stop. Do not use it.
   - A commercial library EULA: check it covers this kind of product,
     the target platforms, distribution and modification. If unsure, stop
     and ask.
3. Add the attribution text the licence asks for to the credits file.
4. Add a provenance log line: URL, author, licence and version, files
   used, changes you made, date.
5. Save the licence text or receipt where the profile keeps licences.
6. Commit the sound, the log line, the credits line and the licence copy
   together.

See the [sound-provenance reference](../reference/skill-sound-provenance.md)
for the full decision table.
